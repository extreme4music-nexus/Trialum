## Ubuntu guardrails

- Preserve /opt/trialum/server/.env; maintain localhost-only host API port **8687** (8787 belongs to Readarr on host). Internal API port 8787 and PostgreSQL internal 5432 must not be exposed.
- Never modify router forwarding, Webmin, NAS or the existing WireGuard setup, nor enable public Funnel during private testing. Prefer Tailscale Serve restricted to test devices.
- Execute idempotent migrations 003, 004, 005 **in that order** on existing volume only after PostgreSQL backup AND separate restore rehearsal.
- Never run docker compose down -v on live Ubuntu. Never paste passwords, API tokens, invitation codes, FCM registration tokens or service-account JSON into GitHub, docs, chat or screenshots.
- Keep TRIALUM_SOCIAL_ENABLED=false, TRIALUM_SHARED_ENABLED=false, TRIALUM_MESSAGES_ENABLED=false, TRIALUM_PUSH_ENABLED=false and TRIALUM_FREE_TEXT_ENABLED=false until relevant private QA gates pass.
- Do not rotate TRIALUM_DATA_KEY until a controlled re-encryption plan exists.

Reference: V1.5.6_B_PRIVATE_QA.md, V1.5.6_D_SERVER_MIGRATION.md and V1.5.6_E_SERVER_MIGRATION.md.

## Beta APK install safety

1. Download Android artifact **Trialum-Android-1.5.6-F-beta1-debug** only from a successful GitHub run on main.
2. **Before installation, export and verify JSON backup** from the currently installed app.
3. If Android says “App not installed”, likely the debug signing certificate differs between Actions runs. **Do not uninstall** the previous game without a verified exported save. Set up the stable test signing key or test in another profile/device first.
4. Offline local mode remains usable without online profile. Messages, visits and push need a configured private HTTPS server, opt-in and explicit Firebase setup.
5. Do NOT publish a 1.5.6 AAB or tag version 1.5.6 while these manual gates are pending. The beta is only a build for owner QA.
