## Owner-approved spatial plan
`G-00L` is the service side immediately LEFT when entering the existing greenhouse pad, **NOT another room and NOT any of the four grow fingers**. G02–G05 each remain one bed of five terrestrial plant slots; G01 keeps four aquatic slots. In sample scene `layout-concept` there are **2 RS and 4 RM** purely to demonstrate relative sizes/quantity. These are not measured actual coordinates. Keep main water heart and robot paths clear.

## Explicit system barriers
1. The racks are purposefully EMPTY in review models. The separate `CN01` leaf-filled tray is **DEMO** only; it does not consume/invent canonical seedling stock. Do not duplicate a plant in bed and in mature holding. There is NO standalone mature-plant inventory state in the current engine; creating it requires an approved separate transaction/backup migration.
2. The W03 holo UI is modeled decorative light geometry, **NOT** a data-binding or interactive gameplay command.
3. Side-braces, beams, shelf tiers and chassis are physical 3D mesh parts with metallic/roughness PBR and isolated emissive geometry. No real-time dynamic light objects, ray tracing or phone performance claims.
4. HIGH photoreal replacements should maintain the **same file IDs, dimensions, Y-up pivots, footprint and per-part mounting meaning**, replace meshes/textures only after owner approval.
5. No production branch/Play Store/Android APK changes; use the isolated S7 development PR stack.
