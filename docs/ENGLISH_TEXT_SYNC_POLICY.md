# TRIALUM — mandatory English synchronization rule

**Owner decision, 10 Nov 2026:** Macedonian and English are the two actively maintained text catalogs. Only **missing** English translations should be filled; preserve correct translations. The other 15 UI catalogs are **not** continuously translated now; revisit at explicit milestone transitions **after the Living World roadmap is complete**.

## Mandatory same-change rule (all future feature/fix PRs)

Whenever a change **adds, removes or edits user-visible text anywhere in the game**, including:
- labels, buttons, names of menus/options, dynamic gameplay/status errors and unlock hints;
- tutorials, welcome copy, AI/LLM prompts and warnings, social messages, invitations, notifications, dialogs and accessibility labels;
- text generated by native Android resources and WebView wrappers;

**review the English translation in the same PR, update `locales/en.json` as needed, and extend the relevant automated English UI regression.** Every text-bearing code review explicitly records whether the English strings were synced or already equivalent. Do not rely on a future bulk translation pass.

Use complete `strings` entries for sentences and UI messages. Use `words` only for safe isolated nouns/labels with stable grammar; avoid word-by-word English for complex Macedonian inflections. Keep exact Unicode/punctuation in keys. Never auto-translate user-authored names, pet histories or saved chat messages; preserve intentionally original fictional creature names.

A pull request adding Cyrillic source text without touching `locales/en.json` fails the `english-text-sync` check. Automated detection is deliberately **not** claimed exhaustive: reviewers must also inspect dynamic templates, English-only strings, Android Kotlin resources, and non-Cyrillic labels. Browser UI regression under `TRIALUM_LOCALE_AUDIT=1` verifies the tested English screens contain no untranslated Macedonian text, excluding intentional user content/native language labels.

**Scope freeze:** Do not begin translating ES/DE/FR/... or assume they are complete. Their maintenance occurs at owner-approved milestone transitions after LW; only fix critical safety or blocking instructions earlier if needed.
