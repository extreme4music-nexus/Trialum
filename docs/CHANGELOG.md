# Changelog

## 1.1.0 — 2026-11-07

- Поделена структура: логика, рендер, UI, зачувување, аудио, PWA ресурси.
- Canvas аквариум со селекција преку допир и анимирани фантастични миленици.
- 4 поединечни дневни акции за секое милениче; 4 по биосвет.
- Капацитет на живеалиште кој зависи од видот и растот на милениците.
- Повеќе биосветови, петдневна изградба и преместување миленици.
- Фиктивна микро/макро-биохемија, pH, кислород, температура, чистота и токсини.
- Истражување и создавање 3 вида фантастична флора.
- Звучни ефекти преку ZzFX (MIT), оригинална амбиентална музика и синтетички гласови.
- IndexedDB/localStorage, увоз/извоз на JSON, делумна миграција од верзија 1.0 и дневник.
- In-game сигнали и мост за идно Android поврзување.
- 18 логички regression checks PASS; Chromium browser E2E не можеше да се изврши во оваа ограничена средина.
