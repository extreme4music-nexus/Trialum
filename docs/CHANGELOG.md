# ТРИАЛУМ 1.2 — Еволуција и P2P пријатели

- Независно напредување на секое милениче (XP, возрасни порти, потешки нивоа, морфолошки отклучувања).
- Локален модел 6×6×3 за научно фантастично учење со мали адаптивни тежини.
- Поприродни анимации: екстремитети, опашки, сензори, трепкање, реакции и P2P гостин.
- Рачно WebRTC поврзување без сопствен сервер: покана → одговор → сесија.
- Ограничување едно наградено дружење дневно по другар/миленик.
- Оригинална адаптивна икона за Android.
- Регресиони тестови за еволуција и сигнални кодови.
- Миграција од светови 1.1 без губење на зачувани миленици.

**Важно:** STUN се користи само по избор за NAT откривање. Нема TURN; многу NAT мрежи можат да не се поврзат. Идентитетите не се проверени. Android APK е debug build за тестирање и се проверува преку GitHub Actions.
