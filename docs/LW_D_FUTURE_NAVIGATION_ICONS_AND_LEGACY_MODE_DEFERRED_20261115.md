# TRIALUM — POST-3D-COMPLETION NAVIGATION & LEGACY MODE (DEFERRED)
## Owner design decision · 2026-11-15
**This proposal is RECORDED ONLY. Do NOT implement it during Food Warehouse S4.**
When all rooms, lobbies and the persistent Living World are built and visually/functional owner-accepted:
- Redesign existing LEFT holographic HUD rail to present direct icon/entry links to major lobbies, the world, and all built branches. Do not create a competing menu; continue using the SAME current Living World 3D theme, right contextual HUD and top resources bar.
- Contextual menu items change automatically when entering each branch, as already demonstrated in Agro Atrium S3. A Back/Up navigation action stays consistently located in that left rail. Use a scene registry / route graph; no hardcoded navigation for every visual room.
- Remove decorative **“3D” labels everywhere in the default immersive game**, because 3D is then the normal mode, not a separate prototype or pilot.
- Add a **Legacy Mode** choice for players who prefer the original 2D/non-3D gameplay/UI. Legacy retains original saves and all functional gameplay. Do not delete or fork original game engine. Switching modes must preserve canonical progress and active account, not write inconsistent parallel game state.
- The later design requires explicit owner approval of navigation design, naming, accessibility, Android back semantics, fallback, migration and long-run resource limits.
**Status: PARKED / NOT STARTED. Priority now: Food Warehouse room; then one room at a time.**
