# ТРИАЛУМ 1.4.1 — UI/UX и функционален аудит

## Истражена навигациска шема
Android Navigation Bar documentation: https://developer.android.com/design/ui/mobile/guides/layout-and-content/layout-and-nav-patterns
За мобилен уред, 3–5 главни дестинации се попрегледни од 13 хоризонтални табови. ТРИАЛУМ задржува 5: Лабораторија, Биосвет, Миленици, Истражување, Повеќе. Под „Повеќе“ се: ДНК, Флора, Храна, Пријатели, Галерија, Дневник, Известувања, Поставки.

- HUD на врв: **ден, вкупно XP, заработени кредити, молекули, биомаса, сознание**. XP е збир на досега заработени XP по миленичињата. Кредитите се заработуваат само со играње.
- HUD секогаш прикажан; мобилната навигација е закрепена при дното со 5 јасни копчиња. На desktop навигацијата е над содржината.
- Контекстуални екрани за биохемиски активности, изградба, ДНК еволуција, P2P покани, хронологија/филтер и поставки.
- Сите заклучени можности прикажуваат услови; мртвите tab-ови се забранети.
- Лабораториски, биолошки и истражувачки екрани користат доследен визуелен јазик (аква-зелено, виолетова, темни биокуполи), со читлив контраст и големи копчиња.

## Причини за неработење (потврдени во кодот)
1. `js/expansion-ui.js` имаше `pages={research,food,dna,achievements}`, а функцијата всушност се вика `gallery`. Овој ReferenceError го спречуваше иницијализирањето на експанзискиот UI модул, па повеќе екрани не можеа да се отворат.
2. Во `js/longplay-ui.js`, `habitat()` бараше `previous.render('habitats',s)`, но старата компонента враќа `null`; повикувањето `null.replace(...)` веднаш паѓаше.
3. Се користеа 13 избори во тесен хоризонтален список, што го правеше UI тешко употреблив.
4. Дебаг-копчињата беа отстранети од интерфејсот, а некои action callbacks беа недостасувачки; сега постојат `E.debugToggle`, `E.debugAdvanceDays`, `E.debugGrantResources`, `E.debugPetLevels`.
5. Претходниот Google/мобилен LLM дел беше само stub `isAvailable() === false`; сега вистински GGUF модел може да се преземе и се користи локалниот Android `llama.cpp` runtime, само при изрично започнат разговор.

## Debug safety
Поставки → Дебагирање: вклучување/исклучување, +1/+7/+30 дена, тестни ресурси и нивоа. Не е платен мод. Тестните промени се запишуваат во Дневник и во локалните зачувани податоци. Пред тестови, извези JSON backup.

## LLM model
- Apache-2.0 SmolLM2-135M-Instruct GGUF Q3_K_M ~94 MB, вистинска, но многу мала, претежно англиска генеративна мрежа.
- GGUF се презема **само по експлицитна потврда** откако се исполнети DNA/пет предусловите.
- Model pack е во `model-packs/smollm2-135m/` како декларација; Github Actions `publish-llm-pack.yml` го презема оригиналниот бинарен GGUF и го публикува како GitHub Release asset, без да го запишува во Git history.
- Играта не комуницира со LLM сервер. Android библиотека: `dev.ffmpegkit-maintained:llama-android:0.1.1`, MIT.
- Речникот и интелигенцијата се ограничени; ниеден модел од 135M параметри не може да им парира на големи современи LLM. Android кориснички тестови, термална и RAM проверка се задолжителни.
- При затворање, Native се обидува да го прекине активниот generation job; при секоја завршена генерација го ослободува native model handle.

## QA gate
Автоматски:
- engine/evolution/progression/longplay regression tests;
- `jsdom` mount на вистински `index.html`, отворање на мртвите менија и тестирање на дебаг симулацијата;
- Node синтакса на секоја JS датотека;
- Android compile и артефакт upload.

На вистински телефони:
- пушти нов свет и влези во секое од 5+8 менија,
- провери +1 и +30 денови, ресурси, акции и зачувување;
- додај биосвет, прави биохемиски активности, започни/доврши изградба;
- ДНК еволуирај постоечки Флорикс во Синапсо;
- за пријатели: P2P код преку clipboard/share, два телефона на иста Wi-Fi и на различни мрежи;
- дневник: пребарување, филтри, обновување/бекап;
- 94 MB model download на Wi-Fi, вистинска генерација и никаква работа во позадина; провери дали нема губење на влезен текст, непотребно греење или crash.

**Граници:** Објавување на Play Store не е започнато, плаќања и реклами не се активни, а P2P NAT поврзувањето не е гарантирано.
