# Trialum license transition — 14 November 2026

The project's root `LICENSE` now reproduces the exact **Trialum Source-Available Proprietary Notice v1.0** used in the separate public `trialum-beta` repository.

The previous MIT license text is preserved without changes at [LICENSE-MIT-PRIOR.md](LICENSE-MIT-PRIOR.md) and in Git history. **Already valid MIT license grants remain in effect** for material to which those grants apply. Replacing the LICENSE file does not revoke previously granted reuse, modification, publication or commercial-use rights, nor does it retroactively convert third-party or independently contributed material to proprietary ownership.

The new proprietary notice expresses the owner's desired terms for original Trialum material that the owner may lawfully license on those terms. It is source-available, not an open-source license. GitHub's platform permissions and mandatory legal rights remain unaffected.

Before representing any preexisting code as exclusively proprietary, the rights holder should review ownership, contributor agreements, prior grants and third-party licenses. The public repository being visible does not represent an approved Play Store game release.

This transition changes licensing documentation only; it does not change game mechanics, Android signing, CI, infrastructure or user data.
