# ТРИАЛУМ — Жива искра

Приватен изворен проект за интерактивна симулациска игра. Верзија **1.1.0**: хемиски почетоци, развој на клетки, фантастични миленици со индивидуални дневни акции, живеалишта со биохемија, флора, музика/звуци и Android WebView шаблон.

> Целосно фантастична симулација, не научно точна синтеза на живот.

Изворниот код на играта е со MIT лиценца; ZzFX е под MIT лиценца и се дистрибуира со својата оригинална дозвола.

**За стартување:** отвори `index.html` или пушти `python -m http.server 8000`, па посети `http://localhost:8000/`. **Тестови:** `node tests/engine.test.cjs`. Android шаблонот не е изграден во APK.
