# ТРИАЛУМ — Жива искра · v1.3.0

**Интерактивна игра за измислена еволуција, создавање биосветови и долгорочна грижа за непостоечки суштества.** На македонски јазик. Целиот игровен код работи офлајн, без сервер, сметки или надворешни API-сервиси.

> ⚠️ Станува збор за **фантастична симулација**, а не за точна хемија, реална синтеза на живот или лабораториски протокол. Атомските „единици“, биохемиските процеси, видовите и еволуцијата се измислени за играта.

## Стартување

1. Отпакувај го ZIP-пакетот со зачувување на целата структура.
2. Пробај да го отвориш `index.html` во Chrome или Edge. Ако прелистувачот блокира локални скрипти/складирање, стартувај локален сервер: `python -m http.server 8000` од коренскиот фолдер и отвори `http://localhost:8000`.
3. Избери **Тест-режим** за рачно прескокнување денови, или **Реално време** за игра од 1–2 месеци и понатаму.
4. Притисни **Звук** / **Музика** за да овозможиш оригинална амбиентална музика и измислен говор. Прелистувачите бараат кориснички клик пред стартување на звук.

**На телефон:** директното отворање на повеќедатотечен проект преку менаџер за датотеки може да не работи во сите Android прелистувачи. За вистинска Android инсталација е приложен `android-template/` со подоцнежен WebView APK-пакет; самостојниот APK **не е** компајлиран во оваа верзија.

### Важни ограничувања на P2P

За интернет поврзување може да се користи **јавен Google STUN** за откривање јавни адреси. STUN не е игровен хост и не складира миленици, но е надворешна инфраструктура. Може да го исклучиш со режим *Иста Wi-Fi мрежа*. Без TURN relay некои NAT и мобилни мрежи **нема да се поврзат**. Потребно е двата уреда да ја имаат играта отворена и да си разменат покана/одговор преку постоечки канал (порака, е-пошта). Не постои глобално пребарување пријатели или поврзување додека апликацијата е затворена.

P2P идентитетот во 1.2 **не е криптографски потврден**. Кодови разменувај само со пријатели; другата страна ги гледа твоето доброволно избрано P2P име и прикажаното милениче. Не се испраќа целиот локален свет или резервната копија.

## Симулациски правила

- Фазите не се вистинска биолошка еволуција. Рачно активираш пресвртни точки со научни поени, молекули, клетки и поминати денови. Последната фаза се отвора најрано на **30. ден**; светот продолжува и до 60-тиот ден и понатаму.
- Ново живеалиште бара посебна петдневна изградба. Два биосвета не делат заеднички биохемиски параметри или дневни акции.
- Капацитетот е во **биотовар**, пример: мала Лумира зафаќа 1 единица, поголем Кристел може да зафаќа 8. Растот може да предизвика пренаселеност и ќе треба преселба.
- Во реалниот режим, дневната состојба се пресметува кога повторно ќе ја отвориш играта. Прелистувачот **не извршува JavaScript додека е затворен**. Ако играта стои долго затворена, при отворање обработува максимум 365 дневни итерации.
- Глад/радост/чистота под 35% и квалитет на живеалиште под 58% создаваат внатрешни сигнали. За системски известувања додека играта е затворена е потребен Android native слој (погледни `android-template/`).
- Играта не предвидува трајна смрт на милениците додека ја немаш отворено. Ќе имаат незадоволени потреби, но можеш да се вратиш и да се погрижиш.

## Зачувување и приватност

Светот е локален на еден уред/прелистувач и на истиот origin. **Нема cloud sync.** Податоците се во IndexedDB, со fallback во localStorage. За сигурен пренос или архивирање кликни „JSON бекап“. Дневникот не се кратe при зачувување; само последните 120 записи се прикажуваат во екранот за брзина. JSON ги содржи сите записи.

> Бришење „site data“, промена на прелистувач, режим на приватно прелистување или отворање од друга адреса може да го направи локалниот свет недостапен. Чувај редовни резервни копии.

## Код и тестирање

```
index.html                Главен интерфејс
assets/style.css          Одделен дизајн
assets/icon.svg           Оригинална икона
js/engine.js              Правила (тестирачки, без DOM)
js/world.js               Canvas сценa и директно селектирање
js/app.js                 UI, навигација, дејства
js/storage.js             IndexedDB/JSON/миграција

vendor/zzfx.min.js        ZzFXMicro v1.4.0 (MIT)
vendor/LICENSE-ZZFX.txt   Приложена MIT дозвола
manifest.webmanifest      Основа за PWA
sw.js                     Offline cache кога е преку HTTPS
tests/engine.test.cjs     Автоматски логички тестови
android-template/         Изворен Android Studio шаблон
docs/                     Детална документација
```

Тестови: `node tests/engine.test.cjs` (Node.js >= 18). Android Studio проектот е **неизграден и нетестиран**; HTML game engine има автоматски тестови. Во одредени затворени окружувања browser automation е блокиран со политики — тоа не е знак за грешка на играта.

Поврзаниот GitHub конектор во оваа сесија може да чита и менува содржина во достапни репозиториуми, но нема функција за **создавање нов приватен репозиториум**. Затоа репозиториумот не е создаден автоматски.

Со GitHub CLI на твојот компјутер, во коренот на отпакуваниот проект:

```bash
git init
git add .
git commit -m "TRIALUM: Ziva iskra v1.1"
gh auth login
gh repo create extreme4music-nexus/trialum-ziva-iskra --private --source=. --remote=origin --push
```

Потоа може да се користи поврзаниот GitHub за понатамошни измени. Не додавај приватни бекапи или податоци од милениците во репото.
