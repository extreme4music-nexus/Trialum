# ТРИАЛУМ — мал вистински LLM пакет (0.1)

Ова е **вистински претходно трениран јазичен модел**, не симулиран генератор на пораки.
Пакетот е одвоен од играта и APK-то, за преземање само по избор од корисникот.

## Модел
- HuggingFaceTB / SmolLM2-135M-Instruct, Apache-2.0 (потврди во оригиналната model card).
- GGUF quantization Q3_K_M, приближно **94 MB**; сметаме на значително помала интелигенција од големите LLM модели.
- Производен GGUF извор: https://huggingface.co/unsloth/SmolLM2-135M-Instruct-GGUF/blob/8637628433dc3df4a2d363adc89e4c3917f299dc/SmolLM2-135M-Instruct-Q3_K_M.gguf
- Пакетот за GitHub Releases се создава преку `.github/workflows/publish-llm-pack.yml`.
- Во кодот се испраќа само *локален* краток prompt до моделот; никакви cloud API барања за чет разговор.

## Како се користи
1. Достигни вид Синапсо или повисок, со потребните нивоа/ДНК лабораторија.
2. Отвори Миленици → Разговор со миленик → Преземи мини LLM (прибл. 94 MB).
3. Апликацијата презема GGUF директно од јавниот upstream и го складира во својот приватен простор.
4. Напиши кратка реченица, притисни Испрати. Android native llama.cpp компајлирана библиотека го извршува моделот локално на CPU.
5. Кога ќе ја напуштиш апликацијата, нови генерации не се стартуваат и активниот job се откажува.

**Ограничувања:** Моделот е многу мал и речиси исклучиво англиски. Не ветуваме човечка интелигенција, долги разговори или сигурни македонски одговори. Проценката за меморија/батерија и реалната брзина се потврдуваат на телефон. Во ниеден случај нема купувања и нема испраќање чет на сервер.
