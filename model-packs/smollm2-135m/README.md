Реалната Google синхронизација и судир меѓу две облачни верзии сè уште чекаат тест на два уреда. [Целосно упатство](../../docs/GOOGLE_PLAY_GAMES_V1.5.4.md).


> **Актуелна развојна фаза — 1.5.3 (Android SDK 36):** изолиран Android build врз потврдената 1.5.2. `compileSdk=36`, `targetSdk=36`, `versionCode=19`, Gradle/AGP/Kotlin ажурирани само за компатибилност. **Игровните механики и локалниот LLM/P2P не се менуваат.** Главната `main` останува 1.4.1; ова **не е RTM**. Потребна е физичка проверка на телефонот пред следната фаза. [Точен SDK36 план и QA](../../docs/ANDROID_SDK36_V1.5.3.md).


> **Статус на 8 ноември 2026:** ТРИАЛУМ **1.5.1** е **развојна Android/HTML beta** во гранката `feature/trialum-v1.5.1-final-polish`. Стабилната `main` сè уште е **1.4.1**. Не е RTM, Play Store release или потврдено функционална на физички Android уред. Пред експериментално инсталирање на debug APK извези JSON од 1.4.1; различни debug потписи можат да бараат деинсталација.

**LLM пакетот останува ист во 1.5.1.** Нема промена на GGUF, checksum, лиценца, cloud policy или native runtime; сите нови визуелни/медиумски функции се независни од моделот. Пред RTM потребен е посебен реален Android on-device тест.


**Статус:** ТРИАЛУМ **1.4.1** е постојниот функционален **debug/test build** и **можен релис-кандидат по неколкудневно рачно тестирање**. Не е прогласен за конечен релис, нема Play Store објава и оваа документациска ревизија **не менува код, APK или број на верзија**.

Ова е **вистински, но многу мал претходно обучен јазичен модел**. Не претставува свест, општа интелигенција или трајно дообучување. Неговите тежини не се вградени во основниот APK.

## Како се презема

**Патеката за корисникот:** во играта достигни **Синапсо+**, миленик **ниво 22+**, лабораторија **6+** → **Миленици → Вистински локален LLM разговор → Преземи**. Апликацијата го презема GGUF **директно од pin-уваниот Hugging Face URL** во приватниот app storage и го користи офлајн по првото преземање.

**GitHub Release:** [trialum-mini-llm-v0.1](https://github.com/extreme4music-nexus/Trialum/releases/tag/trialum-mini-llm-v0.1) е ZIP архива со GGUF, manifest, checksum и лиценца, создадена од [workflow](../../.github/workflows/publish-llm-pack.yml). **Нема вграден екран за увоз на ZIP моделот**; ZIP не е JSON бекап. Не ги ставај тежините во Git history.

## Реални граници

- Моделот е главно англиски; одговорите на македонски може да бидат слаби и неточни. Не е еквивалент на голем LLM.
- Прозорецот за контекст и одговорите се кратки; не постои вистинско дообучување на тежините при играње. Локалната историја на пораки **не значи** неограничена долгорочна LLM меморија.
- Генерирањето се иницира само при испратена порака и кодот се обидува да го откаже при напуштање на апликацијата. Реалната native CPU потрошувачка и прекинување **се уште се непотврдени на телефон**.
- Нема облачен inferencing; преземањето на тежини бара интернет и upstream hosting може да види мрежни метаподатоци.
